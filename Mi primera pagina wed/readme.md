## Descripción del sitio web

Mi Pagina Web es un proyecto desarrollado en Visual Studio Code utilizando el lenguaje HTML. Su proposito es aplicar los conocimientos de desarrollo web mediante la creacion de diferentes paginas que contienen menus de opciones, autobiográfico, tablas con imágenes, listas y formularios.
